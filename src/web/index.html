🔗 URL Protocol Handler Demo

About This Demo

This application demonstrates how to implement URL protocol handling with Node.js and Electron. The flow includes:

  • Opening a web page from the desktop app
  • Completing authentication in the browser
  • Redirecting back to the desktop app with parameters
  • Handling the custom URL protocol (myapp://)
